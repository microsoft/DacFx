# Release Notes

This update brings the below changes over the previous release:

### Added
* Includes Microsoft.ApplicationInsights.dll with Microsoft.Build.Sql SDK.

### Changed
* Updated DacFx version to 170.5.96.
* Changed the default TargetFramework from net472 to netstandard2.1 for non-NetCoreBuild projects [#791](https://github.com/microsoft/DacFx/pull/791).
