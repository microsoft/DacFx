# Release Notes

## Microsoft.Build.Sql 2.4.0

This update brings the below changes over the previous release:

### Fixed
* Fixed inline SQLCLR compilation in SDK-style SQL projects. Set `EnableSqlClr=true` and build with .NET Framework MSBuild targeting .NET Framework; `dotnet build` does not support SQLCLR compilation. [#870](https://github.com/microsoft/DacFx/pull/870)

### Changed
* Updated DacFx to 170.6.60. See the [170.6.40-preview](../Microsoft.SqlServer.DacFx/170.6/170.6.40-preview.md), [170.6.56-preview](../Microsoft.SqlServer.DacFx/170.6/170.6.56-preview.md), and [170.6.58-preview](../Microsoft.SqlServer.DacFx/170.6/170.6.58-preview.md) notes for DacFx changes.
* Updated Microsoft.Data.SqlClient to 6.1.8.
* Updated Microsoft.SqlServer.TransactSql.ScriptDom to 180.154.0.
* The default TargetFramework for non-NetCoreBuild projects is netstandard2.1 instead of net472, as also noted in the 2.3.0 release notes. [#791](https://github.com/microsoft/DacFx/pull/791)
