# Release Notes

## Microsoft.SqlServer.DacFx 170.5.94-preview

This update brings the below changes over the previous release:

### Adds
* Adds support for running DACPAC pre-plan scripts before deployment planning.
* Adds `DacExtractOptions.PermissionGranteeScope` and the `DacPermissionGranteeScope.DatabaseRolesOnly` option to extract only permissions granted or denied to database roles. The default continues to extract permissions for all database principals, and the option is available through SqlPackage extract properties.
* Adds `IncludeAll()` and `ExcludeAll()` methods to `SchemaComparisonResult` for changing the inclusion state of all excludable schema differences.

### Fixed
* Fixes cloud BACPAC imports with vector indexes failing before table data is loaded by allowing vector index creation to complete during the data phase.
* Fixes Azure SQL extraction losing user-to-login mappings for Microsoft Entra external logins or conventional SQL logins [#571](https://github.com/microsoft/DacFx/issues/571).
* Fixes SQL71558 identifier-casing warnings being reported for references resolved through synonyms [#819](https://github.com/microsoft/DacFx/issues/819).
* Fixes SR0007 incorrectly reporting nullable-column warnings for the NULL-safe `IS DISTINCT FROM` and `IS NOT DISTINCT FROM` predicates [#825](https://github.com/microsoft/DacFx/issues/825).
* Fixes `DacPackage.Unpack` allowing package part paths to resolve outside the requested destination directory.

### Changed
* Removes the experimental `LogDeployment` and `EnableFastComparison` options from public deployment APIs and SqlPackage deployment properties.
