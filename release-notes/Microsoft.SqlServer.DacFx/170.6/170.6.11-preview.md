# Release Notes

## Microsoft.SqlServer.DacFx 170.6.11-preview

This update brings the below changes over the previous release:

### Adds
* Adds managed API support for scoping deploy, script, and report operations to selected schema objects and their dependencies. Scoped operations block by default when a change would break an object outside the selected scope.
* Adds managed APIs for supplying compile-time metadata for unresolved cross-database and self-references when creating a standalone DACPAC, without embedding referenced DACPACs.
* Adds support for `CREATE EXTERNAL DATA SOURCE` in Fabric Warehouse projects.
* Adds support for `GROUP BY ALL` and `ORDER BY ALL` in Fabric Warehouse projects, including deployment and schema comparison for views, stored procedures, and inline table-valued functions.
* Adds build-time warnings for pre-plan scripts that contain full-text or index operations that cannot safely run inside the deployment transaction.

### Fixed
* Fixes extraction of user-defined `cdc` schemas when Change Data Capture is not enabled, preventing those schemas and their objects from being omitted from imported SQL projects. [microsoft/vscode-mssql#22100](https://github.com/microsoft/vscode-mssql/issues/22100)
* Fixes generated SQL used by data import/export and encrypted-column deployments so database and object names containing apostrophes or closing brackets are handled correctly.

### Changed
* Updates Microsoft.Data.SqlClient from 6.1.5 to 6.1.7 for the latest servicing and security fixes.
* Updates .NET Framework SQL project incremental builds to use a hardened cache format; incompatible build caches are regenerated automatically.
