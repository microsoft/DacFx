# Release Notes

## Microsoft.SqlServer.DacFx 170.6.35-preview

This update brings the below changes over the previous release:

### Adds
* Adds public `TSqlModel` APIs for loading, removing, and querying DACPAC and SQL project references, including navigation of referenced objects for IntelliSense integrations.

### Fixed
* Fixes deployment history initialization failures on Fabric SQL Database and Fabric Warehouse.
* Fixes `PrePlanScript` handling so SQLCMD parsing errors trigger failure and rollback, and DACPACs containing table data are rejected before pre-plan scripts run.
* Fixes deployment scripts for temporal tables whose schema or table names contain apostrophes, closing brackets, or Unicode characters.
* Fixes generated placeholder passwords in extracted DACPACs that could cause publishing to Azure SQL Database to fail password-policy validation. [#852](https://github.com/microsoft/DacFx/issues/852)

### Changed
* Updates Schema Compare to reduce repeated dependency processing when including or excluding differences, improving responsiveness for large comparisons.
* Reduces memory usage during extraction, model resolution, and source-position tracking.
