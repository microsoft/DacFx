# Release Notes

## Microsoft.SqlServer.DacFx 170.6.56-preview

This update brings the below changes over the previous release:

### Fixed
* Fixes BACPAC export failures with SQL71501 unresolved-login errors for Microsoft Entra users in Azure SQL Database.

### Changed
* Updates fast comparison to skip reading the target schema for unchanged publishes when `LogDeployment` and `EnableFastComparison` are enabled. Skipped publishes no longer produce target-model validation warnings; deployments using deployment contributors retain target schema loading. [#828](https://github.com/microsoft/DacFx/issues/828)
* Updates Azure SQL Database deployments to create Microsoft Entra users as external users rather than mapping them to Microsoft Entra server logins.
* Updates `Microsoft.SqlServer.TransactSql.ScriptDom` from 180.140.0 to 180.154.0.
* Updates `Microsoft.Data.SqlClient` from 6.1.7 to 6.1.8.
